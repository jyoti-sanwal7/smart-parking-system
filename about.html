About Smart Parking

Smart Parking System is an IoT based project designed to reduce parking problems and improve traffic management using smart sensors and web technology.

It helps users find available parking slots in real time and improves efficiency in crowded areas like malls, hospitals and cities.

Our Mission

To build a smart, efficient and automated parking system using IoT technology.

Why We Created This Project

Parking Issues

Drivers waste time searching for parking spaces.

Traffic Problems

Unmanaged parking increases congestion and pollution.

Smart Solution

IoT provides automated real-time parking management.

How It Works

Step 1

IR sensors detect vehicle entry and exit.

Step 2

ESP32 sends data to Firebase via WiFi.

Step 3

Website shows real-time parking availability.

Our Vision

To develop smart city solutions that improve transportation and reduce traffic problems using technology.
