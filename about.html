About Smart Parking

The Smart Parking System Using IoT is developed to provide an efficient and automated solution for managing parking spaces. The system uses IR sensors to detect vehicle entry and exit, an ESP32 microcontroller to process data, and a servo motor to control the parking gate automatically.

It continuously tracks the number of available and occupied slots, displays the information on an LCD screen, and updates real-time data to a Firebase database. Users can monitor parking availability through a web dashboard from anywhere.

Our Mission

To design and develop an intelligent Smart Parking System using IoT technology that efficiently manages parking spaces, reduces traffic congestion, saves time, and improves the overall user experience through automation and real-time monitoring.

How It Works

Vehicle Detection

IR sensors detect vehicle entry and exit.

Gate Control

ESP32 controls servo motor to open/close gate.

Slot Counting

System updates available and occupied slots.

LCD Display

Displays parking status and slot availability.

Cloud Integration

Data is sent to Firebase via WiFi.

Web Dashboard

Users can monitor parking slots online in real time.

Working Flow

System starts and connects to WiFi.

LCD shows total and available slots.

Sensor detects incoming vehicle.

Gate opens if slot available.

Slot count increases on entry.

Slot count decreases on exit.

Data updates to Firebase in real time.

Future Enhancements

Future improvements to enhance system efficiency, automation, and real-world usability.

Mobile Application

A mobile app will allow users to book parking slots in advance for easier and faster parking management.

Online Payment System

A digital payment system will allow users to pay parking fees online using UPI or cards, making the process faster and cashless.

Camera-based system can be added to automatically detect vehicle number plates for secure entry and exit without manual checking.

Expanding Firebase integration to a full cloud system will allow better data storage, analytics, and multi-location parking management.
