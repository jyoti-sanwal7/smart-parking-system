Smart Parking System Using IoT

A smart solution that helps users quickly find an available parking slot using IoT technology.
The system detects whether each slot is empty or occupied and displays live updates on a web dashboard, saving time and reducing traffic congestion.

Technologies Used

Core technologies used in this project.

HTML

Used to create the structure of the dashboard.

CSS

Used for styling and responsive design.

JavaScript

Handles real-time updates of parking slots.

Firebase

Realtime database for storing parking data.

IoT (Internet of Things)

Connects hardware with web system for live monitoring.

Arduino IDE

Used to write and upload code to ESP32 microcontroller.

Future Enhancements

Upcoming smart features for better parking management.

Mobile App

Book parking slots using smartphone app.

Online Payment

Cashless parking payment facility.

Number Plate Detection

Automatic vehicle entry and exit system.
