Smart Parking System Using IoT

A smart solution that helps users quickly find an available parking slot using IoT technology.
The system detects whether each slot is empty or occupied and displays live updates on a web dashboard, saving time and reducing traffic congestion.

View Live Dashboard

Key Features

Important functionalities of the Smart Parking System

Real-Time Slot Monitoring

Shows live status of parking slots as Available or Occupied using sensors and Firebase.

ESP32 Based Control

All operations are handled by ESP32 microcontroller for fast and efficient processing.

Cloud Database (Firebase)

Stores and updates parking data in real time for instant web dashboard updates.

Web Dashboard

User-friendly interface to monitor parking availability from anywhere.

Automatic Gate System

Servo motor automatically opens or closes gate based on slot availability.

Fast & Efficient System

Reduces traffic congestion and saves time by eliminating manual parking search.

Technologies Used

Core technologies used in this project.

HTML

CSS

JavaScript

Firebase

IoT (Internet of Things)
